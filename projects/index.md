# Start here

* [What is a JFrog Project?](what-is-a-project.md) - A Project is a workspace in the JFrog Platform that gathers one team's repositories, builds and people, with its own roles and storage quota.

# How Projects work

* [Project roles and members](project-roles-and-members.md) - Who can do what in a JFrog Project: Platform Admins, Project Admins and members, with global and project roles scoped by environment.
* [Project resources, environments and quotas](project-resources.md) - What belongs to a JFrog Project: repositories with the project key prefix, builds, environments, a storage quota, and repositories shared between projects.

# Hands-on

* [Set up a project](set-up-a-project.md) - The steps a Platform Admin follows to create a JFrog Project, staff it, give it repositories and keep it healthy, with JFrog's recommended practices.
